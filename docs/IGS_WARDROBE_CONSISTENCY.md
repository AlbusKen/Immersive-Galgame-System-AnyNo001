# 衣装候选与 CG 一致性

对应 0.36.88 本地未提交草稿。三方审核、用户决定和实际定向结果见 [迁入记录](PR8_PORT_REVIEW_20261016.md)。

## 衣装候选与显示

命名衣装将文字、图和默认选择分开。旧原装/生成槽在启动或保存导入时自动接入命名衣装，初始默认仍指向原图，明确改选另一套才改变显示。基础图与平和图同时有图时全部保留。剧情 CG 的新衣装先保留当次证据与候选；用户确认采用时校验角色、目标、DNA、衣装和图片，新协议还校验模板快照。旧格式继续校验原生成目标，不能因迁入新协议封死旧角色。

说明保存成功而图片失败时保留说明；已有 imageId 的采用失败重试使用原图。楼末候选可复用在途写词，入柜后不重复弹确认；关闭阅读器、切卡、来源或配置变化会使旧任务失效，迟到结果不得覆盖新目标。

待确认立绘可以按当前角色与衣装临时显示；每项到达只失效相关素材依赖。显示使用全局加当前卡库，不借其他卡素材。缓存只保留轻量绑定，像素、下载、租约与对象 URL 统一交给当前中央媒体缓存。

## 一致性重绘

本节的三景别模板和角色一致性重绘仅用于内置 NAI。外部图源的普通生成独立运行：DBGen 保留自身内容生成链，IGS DNA/衣装最多附带文字参考，不要求外部理解或返回内置协议。

CG 库提供一致性重绘入口、进度和候选。服务冻结原 CG、人物绑定、有效衣装、资料及配置基线，必要回退须先确认。原 CG 与参考图通过 media 按需读取；按平和/默认等优先顺序找到一张有效图即停止读取其它表情。

`cg-reference-canvas` 和 `cg-consistency-appearance` 负责参考几何与资料，`cg-consistency-service` 管理写词、局部重绘与候选，UI 只展示并转发明确动作。参考画布/蒙版和 caption 位置共用几何计划。粗区不等于人物精确分割，生成结果和视觉服从无法由程序断言保证。

取消、写词失败、绘图失败、保存失败和目标过期均保留原 CG。接受时重新校验目标、revision、资料、参考和来源租约，再走存储原子更新；原图和原来源快照继续保留，新结果的工作资料另行归档。不会把候选预览直接当已保存结果。

## 当前媒体体系适配

- 业务记录、WAL、文件卸载、备份与 GC 沿用当前实现。原子更新与普通保存分开；相同元数据普通保存不增加版本或重新标记待备份，journal 恢复不改写版本。
- 一致性基线等图像字段进入统一图片字段与引用检查。新引用提交成功后才释放旧引用；删除检查覆盖衣柜、候选、CG 来源、其他角色卡与旧预设，引用读取失败时拒绝清理。
- 候选列表先预留元数据预算再替换，比较快照使用元数据和图指纹，避免复制整份 base64。没有新增独立原图 Map 或后台轮询。
- 静态页只有当前页仍需要且缓存驻留了新显示地址才刷新。失败或未接纳结果不自循环重读；后续明确读取允许恢复。

配置、IndexedDB 与酒馆文件没有共同事务，保留当前失败补偿和引用保护，不承诺跨系统、跨设备原子性。真实图源接受性、视觉收益、真实酒馆存量数据和手机未验收；本轮只保留离线组件与 fake provider 的定向证据。
