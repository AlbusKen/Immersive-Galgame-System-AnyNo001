## 数据与操作

- 新默认唯一来源为 `characterDefaultOutfits[规范角色键] = { version: 1, outfitName }`，界面显示“衣装名称（默认）”；显示后缀不进入真实键。
- 衣装 DNA 通过 `characterOutfits[角色][衣装].wardrobe` 读取 `wardrobe[键].prompt`；人物立绘与表情归该衣装 `moods`。
- “原装”只映射当前默认衣装，不复制图或 DNA。切默认只切选择；从原装页发起的编辑、表情和续画写入实际衣装。
- 旧角色没有新映射时显示未指定。旧 `defaultAppearance`、`entry.default` 和旧原装图保留，但不自动建立新默认或后台迁移。

先在角色所属素材库中选定一套有可用人物立绘的命名衣装，确认衣装 DNA 后使用“设为默认”；或显式生成新默认立绘并成功采用。只有生成而未采用、读取或保存失败，均不建立默认。服装静物图、头像和未采用候选不能代替人物立绘。删除默认衣装或最后可用图前先指定替代。

## 正文与重绘

1. 正文指定的衣装有图时采用同套衣装；缺单个表情先在同衣装回退，不因此换衣。
2. 整套确证缺图或衣装未登记时才按规则选择新默认，保留原始要求和回退原因。读取失败、解码失败与待加载不当作缺图；缺默认或资料不完整时重绘停止，不自动补图。
3. 内置一致性从目标 CG 自身锚点或可靠历史快照恢复要求，不借当前阅读页改写历史。跨衣装回退一次列齐角色、要求／有效衣装与变衣风险，确认前不写词、不绘图；无需回退不额外确认。
4. 发送前和接受候选前复核 CG、图片、衣装、所属库及配置；变化或取消使任务失效，切回旧值不复活原任务。生成后仍须预览并接受才替换原槽位。
5. 校正使用预检冻结的参考人物图与有效衣装，保留原 CG 动作、姿势、构图、尺度、互动与场景；允许身份和衣装的必要局部轮廓变化，不迁移立绘的动态、光照或画风。

参考采用完整图的非透明边界等比 contain，仅修剪完全透明外沿。画布、蒙版、caption 中心和回贴共用几何 plan；75/25 分区、尺寸网格和像素上限保持。完整参考缩小后的细节分辨率仍有限，粗区不是人物分割，不能保证区内道具与接触点不变。

## 保存与恢复

原 CG prompt、recipe、身份／衣装快照和手改 final 不自动重写。工作轮次的有效衣装、回退确认、受控参考标识及发送来源单独归档；旧图缺来源保持未知。图片载荷、外部凭据 URL、完整配置及内存租约不写入新增来源字段。

引用保护覆盖衣柜、其他角色卡、候选、旧预设和 CG 来源，读取不可靠时拒绝清理。保存失败或租约拒绝保留原 CG，文件层只清理本次新文件；配置、IndexedDB 和酒馆文件没有共同事务，不承诺跨系统或跨标签页原子性。回滚程序前备份新格式设置与图片记录，旧版本可能不理解新映射，不自动展开回旧原装字段。
