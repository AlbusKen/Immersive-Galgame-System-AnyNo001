# 演出版面与节奏规范（审查兜底用）

适用：所有 fx-daily 演出、题材包（fx-pack-* 及其 build/style）、常驻氛围层。新做或返修演出照此自查。

## 0. 六把尺子（总标准，逐条过）

细腻、精致、有元素不滥用、主题突出、易用性强、简易好懂。
- 细腻：细线、微光、轻动、柔和过渡；不粗框、不硬切、不闪烁。
- 精致：对齐等距、线宽圆角统一、成套同源；不拼凑、不随手坐标、不贴边。
- 有元素不滥用：题材特色元素只点一两处；不满铺纹样、不堆道具。
- 主题突出：一眼看出在演什么，一个焦点；不东一块西一块、不抢画面。
- 易用性强：触控 ≥40px、手机可用、不挡对话框和操作、可关可调。
- 简易好懂：一看就懂，文案短而书面，不加括号解释、不放统计元数据。

**去拟物**：除童话、绘本等童趣题材外，不做特别拟物化或卡通化的演出（纸纹、木纹、金属、回形针、印章、卡通道具插图）。题材感用线、点、字、光、色调与负空间表达。COC/恐怖调查 = 阴冷、透明、无机质。

**禁止色块冒充画面（硬规则）**：镜子、车窗、水面、屏幕、取景框、相框、回忆框、画中画、放大镜、蒙太奇格、分屏等「框里该有场景」的演出，框内必须是真实画面——当前背景复刻（readStageBackground/layerStyle）与立绘复刻（cloneSpriteLayer/resolveRegionCrop），按需翻转、裁切、调色、模糊。禁止用渐变色块、纯色平涂假装场景内容。读不到画面时退为极淡中性雾面或不显示该框，绝不出现彩色渐变占位。演出也不得给整台铺不透明暗幕遮掉背景和立绘（压暗 ≤25%）。注：验孕棒、奖杯、戒指、蛋糕等物品道具本身就是物件，不是「画面容器」，此规则不适用——物品做成细线轮廓+光影暗示的图标风格即可，不必做成背景复刻。

## 1. 画面构图

- **一个焦点**：一次演出只有一个主视觉（卡、道具、文字其一）。辅助元素围绕焦点，不另起一处抢眼。三个以上互不相干的小块散在画面各处 = 东一块西一块，必须合并或删。
- **锚定而非漂浮**：元素要么锚在人物（头部锚点、手、身侧），要么锚在画面结构（中轴、三分线、地平线、对话框上沿）。不允许"随便给个 left:37% top:23%"。
- **对齐网格**：主体水平居中或落在三分线（33% / 67%）；同组多个元素共享同一基线或中线，间距相等。
- **安全边距**：可见内容距舞台边缘 ≥ max(16px, 4%)；距对话框上沿 ≥ 12px（用 `--igs-fx-safe` / `--igs-fx-vis`，禁止写死离底百分比）。刘海/圆角屏用 `env(safe-area-inset-*)`。贴边只允许"有意出血"的元素（黑边、窗框、取景框边线），且四边对称。
- **不挡脸**：主体卡片不压在说话人脸部；需要靠近人物时放在头侧并让位到远离中线的一侧（参考 favortip、kp 的做法）。
- **尺寸有度**：主卡宽 ≤ 舞台 72%（竖屏 ≤ 88%）；同一演出内字号最多 3 级；正文字号手机上 ≥ 12px，装饰小字 ≥ 10px。
- **层级清楚**：压暗 → 道具/卡片 → 文字 → 光效。光效不压文字；压暗终点在对话框上沿之前渐隐。

## 2. 视觉质感

- 装饰用实色 + 细描边，不用多层半透明叠加（光束、暗角、柔光例外）。
- 配色取自当前皮肤/世界观变量或包内 2–3 个主色；一场演出不超过 1 个强调色。
- 线宽统一（1px / 1.5px / 2px 三档），圆角统一（同一卡片内一致）。
- 文字有底：直接压在背景上的文字必须有实色底板或描边，避免糊在复杂背景里。

## 3. 节奏

- 入场 200–450ms（ease-out），停留由内容决定，退场 200–350ms（ease-in）；多个元素依次入场的间隔 60–120ms，总入场不超过 1.2s。
- 退场要干净：所有子元素随根节点一起退，不能有残留粒子或晚到的元素。
- 同一页多个演出同时触发时，后者让位（延后或缩为角标），不叠两张主卡。
- 声画同拍：音效起点与关键画面帧差 ≤ 50ms。

## 4. 性能红线

- 动画只动 transform / opacity；`filter`、`box-shadow`、`backdrop-filter` 不做逐帧动画（一次性过渡可以）。
- 不对大面积元素做 `filter: blur()` 动画；常驻层零逐帧计算。
- 同屏动画节点 ≤ 60；粒子类在 `data-igs-quality="low"` 下减半或静止，`env.reduced` 静止。
- `cloneSpriteLayer` 一场演出最多 3 份，演出结束必须移除。
- 定时器、WAAPI、事件监听在演出结束/翻页/关闭阅读器时全部清理；后台标签页不跑循环。
- 不在每页渲染里深拷贝配置或缓存（项目规则：共享只读，写时浅拷）。
