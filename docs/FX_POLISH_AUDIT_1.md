# 日常演出润色审计 第 1 轮（V 端 fx-daily 系，36 个 kind）

只读审计，未改任何源码。读的文件（以审计时的当前内容为准）：

- `app/src/visual/igs-ui/fx-daily.js`（BUILDERS 与 DAILY_RESULT_LIFE_MS）
- `fx-daily-style.js`（样式）
- `fx-daily-sfx.js`（音效 DEFS）
- `fx-daily-particles.js`（烟花 / 孔明灯 / 飘花）
- `fx-eat-style.js`（eat 不在 fx-daily BUILDERS 里，走漫画符号系统）
- `app/src/scene/fx-era.js`（古代 / 现代专属拨除表）

评级口径：占位 = 只有文字 / emoji / 单图标 / 一闪而过；简陋 = 有动画但单薄；可用 = 结构完整、不丢人；精致 = 用了立绘 / 镜头 / 声音协同，节奏完整。

## 0. 总览

| 评级 | 数量 | kind |
|---|---|---|
| 精致 | 2 | photo, fireworks |
| 可用 | 16 | timeskip, letter, alarm, omikuji, receipt, tv, eat, blackout, knock, brake, depart, arrive, ticket, splash, sleep, wake |
| 简陋 | 14 | note, bell, broadcast, touch, gacha, score, pat, poke, cheers, cook, murmur, steam, shower, hairdry |
| 占位 | 4 | rps, game, fever, cat |

### 共性问题（比单个 kind 更值得先治）

1. **立绘基本不参与。** 36 个里只有 photo（复刻立绘进相框）、poke、brake、depart、eat 真正动了立绘。touch、pat、cheers、cat、shower、steam、hairdry 这类“人物反应”演出，立绘纹丝不动，只是在画面上叠一层图形。
   - 可用 `playSpriteSpec`（WAAPI add 叠加，结束自动还原）。
   - 定位用 `spritePosX` 和 `headTopAnchor`（say 已在用）。
2. **音效张冠李戴（零成本能修的）。**
   - cheers 用 `touch`（心跳咚咚），应是玻璃碰杯叮。
   - cook 用 `lantern`（一阵夜风噪声），应是煎炒滋啦加成品叮。
   - fever 用 `paper`（纸声），应是体温计电子滴。
   - rps 和 cat 都用 `sticky`（便签啪），不贴切。
3. **数字 / 结果类没有节奏。** score、fever、game、rps 的结果直接出现，没有“悬念 -> 揭晓”。B3 ticker（数字滚动）还没接。
4. **“卡片类”全挂在 front 层居中或角落。** 大多是一张静态卡 + 一个入场动画，没有“入场 - 停留 - 退场”三段式，也不联动背景调色。
   - 可借 B5 `data-igs-fx-state` 滤镜（醉酒 / 热 / 暗）给 fever、blackout、steam 压背景。
   - 可借 B11 mist 给 steam、shower。
5. **reduced 兜底整体到位**（`.is-reduced` 一刀切 `animation:none`，关键元素 opacity:1），不是问题；少数点见各行。
6. **世界观变体不均。** 只有 timeskip、letter、note、omikuji、broadcast 有 7 套换皮；touch、pat、cheers、cook、score 等在古代 / 魔法下只是同一个现代图形。
   - 古代模式下 `bell broadcast alarm receipt tv gacha game score ticket shower hairdry photo` 被 fx-era 拨掉，不会出现。
   - cheers、cook、cat、pat、touch、fever 不在拨除表里，古代也会出现，但画面是 🥂 和 SVG 手，缺古风版（酒盏 / 灶台 / 暖手炉）。

## 1. 逐个审计表

量：S ≈ 半天内（CSS / 少量 DOM / 音效微调），M ≈ 1 到 2 天（新增结构 + 立绘联动 + 音效），L ≈ 2 天以上（新积木或多变体）。

### 顺手可批量做的 S 级小修（不占前 10，但一次提交就能做完）

- **修音效错配**（只改 builder 的 `sounds`，并在 sfx 中补三个 DEFS）：cheers 改玻璃碰杯叮；cook 改煎炒滋啦 + 叮；fever 改体温计滴；cat 改软毛窸窣。
- **alarm 去掉现实时钟**：无 time 字段时改读场景时间。
- **bell / broadcast**：画面与声音对齐，bell 用“铃体震动 + 声波圈”，broadcast 逐句出字。
- **note**：飞来贴上 + 撕下退场。
