# test-v0.36.63 CG 正文锚句作用域修复

风险 R4：统一标记边界、数据库生图规划日志、发布文件及测试标签流程。

## 根因与修复

四个锚句在用户提供的原文中均逐字出现，旧函数也返回了 `mode: exact` 和 `anchorIndex`。拒绝发生在后续安全插入阶段：思维链中作为规则名称引用的 `<sentence_hard_constraints>` 没有闭标签，被全文 HTML 扫描错误延伸到正文。原日志把安全插入失败误报为锚句没找到。

- 闭合思维链整块处理，内部未闭合示例不参与后续正文的标签、括号和代码配对。
- 逐个识别真实 `<content>` 开闭标签，跳过代码、注释和思维链中的示例；每段正文独立检查结构，保留原始偏移。
- 有正文容器时锚句只在正文中查找，继续按精确、规范化、最长公共子串的优先级定位。
- 正文内完整对白、HTML、代码和整行保持原样，标记独占行且留在正文容器内；真正未闭合的正文结构仍拒绝插入。
- 规划日志区分「正文未命中」和「命中后无法安全插入」，混合失败分别计数。安全标记写回后才请求出图。

复用既有结构检查和标记写入入口，新增内部正文范围 helper；没有新增公开 API、缓存、数据库或后台任务。
