# 演出润色审计 4：区间/瞬时标签、恋爱感官、物品与结果卡、天气时段、战斗

范围与方法：只读源码审计，未真机/未截图。「实际画面」由 CSS 关键帧、DOM 结构、时长常量和音效调用反推，凡写「推断」的是没有逐条核对 CSS 全文。V=app/src/visual/igs-ui/，S=app/src/scene/。

评级标准：占位（只有文字/符号/一闪而过/几乎看不出）、简陋（有画面但单层、静态或与名字差距大）、可用（元素齐、有动画，缺层次或声音）、精致（多层、有声、有世界观/low/reduced 分支）。工作量 S（半天内）、M（1 到 2 天）、L（3 天以上）。

可用新积木（STAGING_EXPANSION_PLAN 第 1 章）：B1 stage-snapshot（复刻立绘/背景）、B2 panel-kit、B3 ticker（数字滚动）、B5 state-filter（持续滤镜区间）、B6 warp（异化滤镜）、B9 crop-frame（局部裁切）、B10 gauge、B11 mist（气雾）。

## 7. 最该先润色的前 10 个

排序依据：使用频率（几乎每个故事都会出现）、与名字的落差、改动成本、是否能顺带抬高多个演出。

| 名次 | 项目 | 理由 |
|---|---|---|
| 1 | 回忆/梦境区间（#1、#2） | 叙事里最常用的两个区间标签，目前只是滤镜+雾，且没有进出转场与声音；改入场白闪、颗粒/重影、BGM 低通即可明显提升，M 级收益最大 |
| 2 | 镜头冲击+震动+心跳（#16、#15、#11） | 情绪触发的演出每个故事都会出现，三者共用冲击音与节拍，一起调参（峰值、过冲、色差、同拍声音）成本 S 却立刻「有力」 |
| 3 | cutin 角色切入（#10） | 名字预期是动漫必杀切入，现在是一条小脸横条；加背板速度线、冲出放大、短音即可，且 B9 裁切可复用 |
| 4 | confess 告白（#18） | 全剧情最高光时刻之一，现在只有黑边+粉暗角；花瓣/柔焦/BGM 抽空能直接抬高情感高潮 |
| 5 | 结果卡/检定骰（#35） | 名字是骰子，实际是数字滚轴；COC/无限流/恋综等题材都依赖，B3 ticker 已在积木计划里，同时抬高后续多个题材包 |
| 6 | 关系变化卡+恋爱回忆（#23、#24） | 恋爱线核心反馈，两者一个是普通 toast、一个是小胶囊，改成划去旧值/相纸入册后情感回报明显 |
| 7 | letterbox 电影黑边（#3） | S 级成本，补宽银幕裁切放大+入场声就可见效果，且常与告白、回忆联用 |
| 8 | 镜头运镜 focus/closeup/tilt（#17） | 运镜只作用于两层元素，缺视差与聚焦；改立绘锐化+背景暗角、pan 视差，所有用镜头标签的故事受益 |
| 9 | 关灯与伞（#6、#7） | 现代关灯无灭灯过程，伞只是一团暗影；这两个是日常场景高频且落差最大（名字很具体，画面很抽象） |
| 10 | whisper 低语+flash 闪白+nickname 称呼（#4、#12、#22） | 三个都是占位级，且各只要 S 工作量，打包做一轮「小占位清理」性价比高 |

顺带观察：入场/出场转场、BGM 联动（低通、抽空）是多项演出共同缺的一环，建议在 fx-runtime 增加统一的「演出时 BGM 闪避/低通」钩子，一处实现，回忆、梦境、告白、闪白、低语、切入都能复用。
