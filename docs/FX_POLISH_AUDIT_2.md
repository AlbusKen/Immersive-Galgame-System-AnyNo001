# 日常演出润色审计 第 2 份（40 个 kind）

范围：`app/src/visual/igs-ui/fx-daily.js` BUILDERS 中的 guqin go poem edict tea bow spell potion owl broom howler yujian liandan biguan dianxue qinggong yungong opendoor shield tend carry candle pass stance say dressup drape fitting dive bubble vacuum sing dance fish draw music ride clean shopping stroll。
依据：builder + `fx-daily-style.js` + `fx-daily-sfx.js`，只读审计，未改源码。
评级口径：占位（单图标/一闪而过/几乎无画面）、简陋（有画面但薄、与立绘无关联）、可用（成型、有节奏有声音）、精致。
积木编号见 `docs/STAGING_EXPANSION_PLAN.md` 第 1 章：B1 stage-snapshot（读立绘/复刻立绘）、B2 panel-kit、B3 ticker、B4 links 连线、B5 state 滤镜、B6 warp、B9 crop-frame、B11 mist 气雾。

## 0. 总体结论

- 评级数量：占位 7、简陋 10、可用 20、精致 3，共 40。
- 共性短板 1：大多数演出是「屏幕中央画一个 CSS 小物件」，和立绘、镜头基本无关。真正动了立绘的只有 bow、yujian、dianxue、qinggong、shield、carry、stance、dressup 等，位移也只有 1% 到 5%。
- 共性短板 2：入场-停留-退场几乎都套同一条 `igs-dfx-fade`（10% 淡入、86% 后淡出），没有情绪节奏（蓄力、爆点、余韵）。
- 共性短板 3：声音有三处错配或敷衍（见下表「音效问题」）。
- 共性短板 4：`fx-daily-style.js` 里有一批旧版遗留的死 CSS（见第 3 节），只增加体积和误导。
- reduced 兜底：全局 `.igs-dfx.is-reduced *{animation:none!important}`（style.js:229）会让所有动画定格。因此多数 kind 在 reduced 下变成静态画面，部分从 opacity:0 起步的元素需要单独写可见规则，没写的就整块不可见（见各行备注）。

## 3. 代码层遗留（润色时顺手清理）

- `fx-daily-style.js` 第 690 到 770 行附近：玩乐类「第一版」规则里，ride 的 `igs-dfx-ride-lights / ride-track / ride-car / ride-wind`、clean 的 `clean-floor / clean-broom / clean-sparkle`、shopping 的 `shopping-card / shopping-confetti`、stroll 的 `stroll-leaves` 在当前 builder 中都不再生成，是死规则。第二版（771 行起）已用新结构覆盖。
- 同一区域 sing、dance、fish、draw、music 的旧 emoji 规则（`💃 🕺 🐟 🖌️`）被第二版覆盖，但旧规则仍在。
- `igs-dfx-reduced` 下的可见性：guqin 的 ♪、go 的落子、tea 的热气、poem 的墨迹遮罩、edict 的展开，在 reduced 下均无专门兜底规则，需要核对是否定格在不可见状态（遮罩/scaleX(0)/opacity:0 起步的元素定格后可能看不到）。
- 多个 kind（dianxue、carry、shield、tend、dressup、drape、yungong、candle、pass、stance）都用 `spritePosX` 单点定位，不支持多人同屏时指定对象，建议统一用 `spriteElOf(env, who)` + B1 的位置读取。
