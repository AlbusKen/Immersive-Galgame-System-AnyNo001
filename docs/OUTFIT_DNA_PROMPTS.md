# 身份、衣装与生图提示协议

对应 0.36.88 本地未提交草稿。迁入来源为 PR #8，审核与验证记录见 [三方审核](PR8_PORT_REVIEW_20261016.md)。

## 角色资料

旧 DNA 的 `identity/defaultAppearance/negative/triggerWords` 继续保留并使用旧路径。`personality` 是独立性格资料，不替代视觉身份。旧自由文本不能自动拆成三景别。

内置 NAI 的新协议使用角色的 `version: 2`，`views` 中保存 `full_body`、`half_body`、`portrait` 的 `subject/negative`；`partial` 只兼容历史任务。内置首次立绘可同次产生候选身份，图片成功并回读后由采用流程登记。已有角色通过角色页 DNA 区的「启用内置三景别 DNA」明确升级；保留旧字段和图片，后续内置默认立绘补齐资料。缺少内置衍生任务所需景别时明确提示。相同角色使用外部来源时，这些字段仅为文字参考，不要求景别齐全，也不改变外部输出格式。

身份、性格、默认衣装说明、命名衣装和当前图的实际衣装是不同资料。默认映射由 `character-appearance.js` 统一读取；旧原装/生成槽自动接入一套命名衣装，默认映射仍指向同一组旧图；基础图和所有表情分别保留。保存另一套新衣装不自动更换默认，旧 DNA 协议也不因此升级。

## 写词与模板

外部来源可在「生图与AI → 图像来源」明确开启「外部生图前补齐角色 DNA」。缺资料时由 IGS 副 API 按内置资料任务建档并独立保存，已有旧格式继续复用；手动生成先确认，取消可自行填写。该可选步骤不把协议交给外部，也不替换外部完整提示词，详见 [生图配置](IMAGE_GENERATION.md#外部立绘的可选-dna-建档)。

内置默认生图框架版本 31，通过 `prompt-preset` 的 taskMap/modules 与 outputs.format 选择任务；未映射格式停止。角色、图号、景别和模板绑定由程序校验。共享世界书参考块在任务资料前，正式写词用宿主扫描；预览、关闭参考块和 provided 任务不扫描。

PR #10 本轮提示增量（`33bc724e` → `9f92a557`）已接入当前本地代码：新人物三景别 DNA、身份 UC、新衣装，以及 CG 的当次身份、特征摘要和新衣装字段使用逗号分隔的英文 TAG。场景、动作、表情和互动保留各自原画面规则，不扩展成全局纯 TAG 限制。

新正向身份中的发色和资料明确的核心锚点、新衣装主要衣物使用 `1.2::tag::`；只有确认准确的同人标签才使用 `2::Name (Series)::`。普通细节不机械全加权，不编造标签或无来源特征。三景别从同一 TAG 母版删除画外的完整标签，共同标签及闭合权重保持一致；由模型按提示交付，程序不事后补权重。

默认预设按原基线备份和逐块升级，保留用户手改正文、格式映射、角色、顺序与开关。已有 DNA、衣装说明和历史图像保持原值，不自动转 TAG、补权重或重画。可选外部 DNA 建档使用这份内置资料规则，外部插件自己的写词与出图仍保持原协议。

- 默认立绘与指定新衣装先保存说明并回读，再绘图；写词只给目标衣装、角色 DNA 和参考资料，不发送其它衣柜让模型改选。错名回复不被改名套入目标。
- 表情写词使用当前景别身份、当前衣装、用户要求与本次绑定，只输出表情片段；完整构图和底色留在程序侧，不额外扫描世界书。
- 普通 CG 的角色目录保留角色键、token 和可用景别；衣柜目录使用当次编号、角色与名称。完整身份/衣装资料留在程序侧，按合法选择绑定模板；新衣装先供当次 CG 使用，图片回读后成为候选，用户确认才入柜。
- 保存的 recipe、来源和原始资料用于重画/采用核对，不因普通重画重写原图的来源。没有模板的历史图不猜测拆分，手改 final 按原文发送。

活动预设由同一个 PresetRegistry 管理。保存草稿不影响运行；默认升级先备份，只更新可证明未手调的默认文本，保留自定义角色、顺序与开关。旧导入先预览、处理 ID 冲突，再保存/激活；未知字段、未映射槽和宏不能静默丢弃后执行。召回项仅归档或报告。

## 来源边界

内置 NAI 使用本程序的预设、三景别模板和手动凭据，不依赖 DBGen。DBGen 始终保留现有完整内容生成链：由插件读取上下文/世界书/角色库，按原调用决定召回，使用插件自己的预设和 LLM 返回完整 caption，再由插件出图。IGS 仅通过公开 description 附带 DNA/目标衣装文字参考，不要求其理解 IGS 占位符或提供新的协议接口；不替换插件返回的人物词，也不将其当成三景别候选。柏宝绘和智绘姬同样不承担内置协议。内置 CG 一致性模板重绘仅在内置 NAI 使用，外部普通生成不受此功能限制。

旧 NAI 通用负面词仅归档停用，不能再自动拼回请求。显式任务负向、活动预设和已应用画师条目的负向仍生效。NAI 只有 429 自动重试；停止本地等待不保证外部任务或计费停止。
