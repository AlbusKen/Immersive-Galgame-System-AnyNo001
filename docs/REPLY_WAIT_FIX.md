# v0.36.48 回复等待修复

## 原因与处理

旧观察器在生成期间静默 30 秒后把请求视为结束，120 秒计时也会无条件收起演出；没有新楼的结束和空楼被当作成功收尾。另有小游戏结算先移除等待层、异步换楼失败仍收起演出的路径。

完成现在依赖结束事件，或宿主停止按钮已收起且正文稳定的兼容证据。单纯静默与无活动超时不解除等待；超时仅提示可能仍在请求。收到完成信号后才读取、解析正文，活动版本变化时丢弃旧结果。等待层保留到阅读源替换成功，错误用同一层展示并等待用户返回当前页。

没有新正文、空楼、只有思考或空 content 显示空回；宿主支持失败事件时展示失败，否则结束后没有正文仍展示空回。停止、读取失败、渲染失败、发送失败分别提示。错误直接打断游戏，等待过场关闭时也保留提示；发送失败保留输入。只复用现有模块，新增临时演出状态与内部替换条件，不写聊天、配置或数据库。

- 定向模拟：五种模式空回、半截正文与超时、无新楼、游戏中失败/停止、替换延迟、读取/显示失败、发送失败保留输入、结束后的迟到写入、异步替换期间关闭阅读器。
- `npm run gate` 通过：structure、static、单元 2284/2284、模拟 225/225、perf 与 build；性能烟测 3.48ms，map-gen 419ms，reader-source 138ms。正式/调试 bundle 的自动/手动启动四种检查通过。版本为 v0.36.48，loader 源文与 JSON 一致。
