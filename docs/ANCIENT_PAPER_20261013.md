# 古代文书纸页本地适配（2026-10-13）

风险级别：R3。仅本地改动，不提交、推送、打标签或生成安装包。

## 实际截图反馈修订

2026-10-13 的实际浏览器反馈确认，第一版统一大纸页侵入底部对话区：330×490 预览舞台的信纸约 252×400，覆盖对白约 45px；字条约 236×330，覆盖约 11px。桌面信纸同样覆盖对白。先前 DOM/样式断言没有发现这类像素问题，不视为视觉验收。

本次修订：

- 文书容器使用既有 `--igs-fx-safe` 和 `--igs-fx-vis` 限定在实际可用舞台内。纸页高度不得超过可用区域，信/诗/官方文书上限 340px，字条上限 230px。
- 由真实字量和显式换行计算有界竖排列预算，短信 6–10 行、字条 3–7 行；宽度按列数和当前字号计算，再受父容器宽度限制，不假定预览格总是 390px。超长内容保持横向滚动，不放大成满舞台纸板。
- 字条内距更紧，原始 9 字样本使用 5 行 2 列预算；信件/诗笺样本使用 6 行 4 列预算。实际高度在预算上增加一字余量，容纳毛笔字体度量和中文标点禁则；仍受可用舞台上限约束。正文仍使用 22–27px 的原字号范围。
- 告示增加横排大字标题和双细描边，正文继续小字竖排；明确以「皇榜」开头时标题显示「皇榜」。标题前缀不重复占正文首列，完整原文仍保留在可访问名称中。
- 圣旨底色改为明确黄纸，真实纹理用 multiply 叠加，保留官方方印和轴杆。非告示圣旨的宽度上限为安全容器的 96%，为诏头两列、正文及方印留出横向空间；其他纸页宽度不随之增大。
- 修订后已补真实云浏览器的图录组件截图验收；下方组件测试只证明结构、输入和生命周期，不替代像素检查。

首轮缩小版的真实云浏览器截图已确认信/字条/诗笺不再遮挡对白，500 字长信可横向滚动到落款及朱印，告示横排标题、双细框和黄纸圣旨均生效。它也发现原始 9 字字条因实际换列成为 3 列，末尾「见。」需要横滚才出现；短圣旨方印同样在末列可横滚到达。增加一字高度余量及圣旨宽度后，最终候选于 17:27 UTC 完成云浏览器复验：字条 115×177，默认两列显示全部 9 字；圣旨 284×214，诏头、正文和方印默认同屏。桌面短信 208×214，纸底与对白相隔约 139px；手机长信可到达末尾落款及印章。告示的标题、双细框和方印亦正常。对应截图位于本次工作根目录的 `browser-qa/revision2-paper-mobile.png`、`final-edict-notice-mobile.png`、`final-letter-desktop.png`，长信交互截图为 `revision-letter-long-end-mobile.png`。

## 已实现

- `fx-ancient-paper.js` 统一古代书信、字条、诗笺、圣旨和告示纸页；原有现代分支保留。
- 纸面使用用户确认试作中的真实纸纹，按原有 CSS 取中央区域；不增加灰色折痕，不预留落款页脚。
- 使用独立字体族 `IGS-MaShanZheng`，仅作用于古代文书及抽签纸面；完整 WOFF2 位于 `app/src/visual/igs-ui/assets/fonts/MaShanZheng-Regular.woff2`，按现有构建流程外置分发，不按样例文字裁剪，也不把字体 base64 塞入主程序。未覆盖字符先使用现有随包 `LXGW WenKai`，之后才回退系统楷体/衬线字体；包含「囍」「𠮷」的文本可由随包后备字库覆盖。来源与 OFL 位于同目录 `MaShanZheng-OFL.txt`。
- 长短书信均从右向左竖排，隐藏横向滚动条，提供触控、鼠标拖动、左右键及 Home/End 导航。逐字演出自动跟随新列，读者主动翻阅后停止跟随。
- 落款单独进入最后竖列，落款和透明朱印同组，印迹下缘约在阅读区高度的四分之三处。无落款书信仍保留独立印列；字条不盖印；圣旨、告示使用正方印。印图仅作装饰，不声明可释读的真实印文。
- 抽签保留签筒、签等和既有演出结构，仅替换古代签纸底纹及字体。

## 生命周期与安全

- 原有主卡排队、换页、关闭、重播与取消入口不变。
- 原寿命不变：书信沿用 `1100 + 字数 × 55 + 2800 × 停留倍率`；字条默认 3800ms，诗笺 4200ms，圣旨/告示沿用 `lifeOf('edict')` 的默认 5400ms。
- 新增行为仅绑定纸页自身的事件，无 document/window 监听器、观察器、轮询或新增计时器。
- 动态正文与落款通过原有 `esc()` 转义。减少动态效果时完整静态可读，仍能横向翻阅。
- 纸页阅读区接收拖动/键盘操作并阻止其冒泡；纸外区域保持原演出层点击穿透语义。
- `reader-host.js` 的 document 捕获阶段快捷键处理将纸页阅读区列为独立键盘输入区，避免左右键在到达滚动区前先触发翻页；Escape 仍按原流程关闭阅读器。

## 集成说明

- `ANCIENT_PAPER_TEXTURE` 和 `ANCIENT_PAPER_SEALS` 从 `fx-ancient-paper-assets.js` 导出；`DAILY_FX_STYLE_TEXT` 已聚合文书样式。字体由 `scripts/build.js` 按原有字体管线注册、复制及附带 OFL。`fx-ancient-font.js` 仅保留空兼容导出，不再携带字库。
- 离线图录单独内嵌同一完整 WOFF2 和 OFL，因此图录仍可离线验证字体，不改变正式源码的按需字体分发方式。
- 序列化 DOM 的离线图录必须重新调用 `installAncientPaperNavigation()` 绑定交互。静态查看及即时全文模式使用 `{ followInk: false }`，避免初次打开时自动跳到末尾。
- 分发含内嵌字体的 HTML 时须附完整 OFL，不只附字体名称或来源链接。
