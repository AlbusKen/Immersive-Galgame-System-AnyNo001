# 文字演出标记被按句分页切断（v0.36.52）

## 原因

正文先按句分页，再运行文字演出渲染。`{小:一句话。}下一句话。` 在句号后被切成 `{小:一句话。` 和 `}下一句话。`，两页都没有完整标记，渲染正则无法命中，控制字符直接显示在对话框。

## 修改

- 提取 `scene/text-fx-markup.js`，分页与视觉渲染共用已有九种效果语法。
- 已闭合标记作为完整结构参与分页，标记内部的句末不切断结构；正文以句末结束时在 `}` 之后断页，闭引号及紧随译文留在同页。
- 保持对白、心理话、后续角色与场景指令的分页坐标一致。关闭文字演出时，完整标记仍能剥离成普通正文。
- 不修改原始消息、用户正则设置、效果类型或渲染长度上限。

## 验证与边界

- 已用截图可见的原文片段在本地重现两页控制字符外漏；提交的测试使用匿名模拟文本。
- 定向测试覆盖九种效果、两种冒号、对白 / 心理话 / 旁白、跨句短语、闭引号、译文、开关关闭、后续指令索引与未闭合写法。
- 阅读器模拟检查实际正文 HTML、翻页与说话人切换。
- 完整门禁通过：structure / static、2315 项单测、234 项模拟测试、perf 与 build；压缩 / debug bundle 的自动 / 手动启动四种组合通过。loader 构建及源文本一致性检查通过。
- 风险 R4；原工作区 17 个既有 WebP 改动保持不变，构建在隔离副本执行。
- 真实酒馆和手机复验待完成，不打版本标签；后续加载 main 候选后复查截图对应页面，确认正文不再外漏标记。
