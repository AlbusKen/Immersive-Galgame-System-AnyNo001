## 恢复与生命周期

- 普通配置提交不取消在途请求，结果和下一步交接沿原快照；真实取消、目标失效和销毁仍结束所属任务。设置关闭和阅读器流式完成会清理或通知对应等待。
- 继续执行须有实际修复进展或相关条件变化。普通本地幂等步骤最多一次无进展重试；写词、出图禁用这一次。错误措辞改变不能重置次数。等待状态保持未完成。
- 模型输出纠正保留原输入、上一份输出及字段诊断。同一字段、槽位和角色的错误不会因换措辞持续发请求。真实模型配置保存、活动预设保存/启用经原入口唤醒；无关配置保存不重发。
- NAI、DBGen、智绘姬、柏宝绘和副 LLM 的生成计时只报告仍在处理，保留同一次调用；副 LLM 的只读模型列表仍保留超时。柏宝绘在调用前取消时零发送，插件忽略取消信号时本地等待也能结束。
- 各来源保持自己的有限重试策略，NAI 仍仅重试 429；发送结果未知不靠盲目重发找回结果。当前没有接通 NAI 的服务端任务查询，因此这类故障仍是未完成边界，不能承诺一定找回图片。
