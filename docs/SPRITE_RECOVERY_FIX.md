# v0.36.59 原装立绘读取恢复与同角色兜底

风险 R4：素材读取、匹配、阅读器事件及发布构建。

## 已证实的程序缺陷

用户报告 v0.36.58 第 40 楼白墨心理页「惊艳」，没有当前服装，原装有图却显示未命中。CG 槽位 94 未就绪时保留正常舞台。诊断只包含最终匹配结果，不能唯一还原旧会话里的失败分支；本轮直接审计并修复程序中可以确定的两个漏洞，不要求手机端调试。

1. 文件读取把网络、HTTP 503 等错误吞成空串；素材服务随后把空串永久加入 lostImages，匹配剔除这些槽。即使服务恢复、图片身份改变或缩略图成功读取原图，原装仍可能一直被排除。
2. 原装未命中时，只因角色已经登记就提前返回；同角色生成图库及当前聊天素材尚未查询，已有图片的兜底被截断。

## 修改

- 原装优先级不变；无可用原装后继续同角色生成图库与聊天素材，包含主名/别名对应。所有现成候选都没有时才决定是否需要补图，空登记角色仍不自动生成。兜底不借其他角色或未选服装。
- 内部严格读取保留文件错误；暂时读不到与确认缺图分开。临时失败短暂冷却，确认缺图也不永久屏蔽；后续正常渲染或访问时可重新读取，静置不请求。没有新增定时轮询或自动重试队列。
- 网络 online 事件清除失败状态并通知现有舞台刷新；有效原图缓存、缩略图路径读到的原图以及图片身份更新即时作废旧失败状态。停止解除监听，清理或停止后的旧任务不能写回状态。
- 失败状态复用中央辅助元数据预算（128 条 / 64 KiB），没有新增像素缓存或数据库。显示探针不把临时失败判成需要重新生图。
- 手机本页诊断补充未命中原因，无需 Console。
