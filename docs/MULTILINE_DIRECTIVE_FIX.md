# 完整跨行对白的识别（v0.36.55）

## 问题

`[igs-char:角色|平和|完整台词。\n\n]` 已有完整闭括号，却先被按物理行拆开。第一行因允许缺闭括号而提前消费，最后的 `]` 成了旁白页。旧 CG 标记移出对白时只收掉两侧各一层换行，也会留下这种跨行结构。

## 修改

- 在统一指令模块识别已闭合的跨行对白与心理话，之后再处理字段、正文格式化和按句分页。正文内部换行折叠为布局空白，保留字词及原始字符位置。
- 遇到下一条指令或正文容器边界时，未闭合标签不继续找远处闭括号，保留已有行尾收口行为。
- 正文、服装、指令提取和 CG 段落编号共用逻辑行；空白行计入原文坐标。CG 标记移植以完整逻辑行作上下文。
- 旧 CG 标记两侧连续的插入换行一起清理；多个 CG 槽号保持顺序。保留 v0.36.53/54 的相邻孤立闭括号兼容逻辑。
- 原消息和图片绑定不修改，不改变锚句匹配优先级或用户正则设置。
